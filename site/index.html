小而完整的三件事

不做知识库、不做聊天窗，只把「在原文旁边说一句」做顺手。

划线，即评论

选中文字右键「添加划线评论」。卡片挂在右侧、和原文对齐、跟着滚动；正文里只留一段淡黄高亮和一个小角标。

@ 一个正在跑的会话

点名一个 Claude Code / Codex 会话，或「用新会话回答」。留言以文件送到它手里；它读完文档，把回复写回原位——或者给出一条修改建议，你一键采纳，原文才会变。

未读一眼看清

别人或 AI 的回复带红点，文件目录里对应文档也挂一枚红色角标，顶部常驻「N 条评论 · M 未读」。看完点「标为已读」，聊完点「解决」；不想要，设置里一键关掉。

评论就是这样一行文本，紧挨着原文存在 .md 里。没有数据库、没有附属文件；Git 能 diff，同步不会丢，卸载插件也还能读。

评论存在哪里？换台电脑还在吗？

就存在笔记本身，紧挨着被评论的那句话，是一段纯文本。随 iCloud / Git / Obsidian Sync 一起走；没装插件的地方打开也能看到。

不用 AI，只当普通评论工具行吗？

完全可以。划线、留言、回复、已读未读都不需要任何会话或联网；@ 是可选项，不用就不会出现。

会把我的笔记发到哪儿去吗？

插件本身不联网。@ 只是往你电脑上的一个文件夹写一个文件，会话在你自己的终端里跑；笔记出不出机器，取决于你配的 AI 工具，与插件无关。首次 @ 需要在「管理成员」里点一次「安装 hook」——它只往 ~/.claude/settings.json 加三条，可一键卸载。
